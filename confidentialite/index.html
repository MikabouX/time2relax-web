En bref

Pas de publicité, pas de traceur, pas de statistiques, pas de cookies, pas d’e-mails envoyés, pas de mot de passe ni d’adresse e-mail demandés.

Sans nom d’utilisateur

Tout reste sur ton téléphone (ou dans ton navigateur sur le site). Rien n’est envoyé.

Avec un nom d’utilisateur (facultatif)

Pour retrouver ton historique sur un autre appareil, l’appli enregistre en ligne :

  • le nom que tu choisis (évite ton vrai nom) ;
  • tes pauses : date, heure, type, durée ;
  • tes réglages : langue, durées, thème, planning des breaks, options de rappel et de paie ;
  • le chrono en cours (effacé après 24 heures).

Jamais envoyés : tes adresses (maison, bureau), tes sites de commande, ta position, tes fichiers. Le scan de code QR se fait uniquement sur le téléphone.

Partage d’horaire

Si tu crées un code de partage, l’horaire que tu partages est visible par qui a ce code. Il s’efface depuis l’appli, ou tout seul après 60 jours sans mise à jour. Pour bloquer les essais de codes au hasard, l’adresse IP d’un essai raté est gardée 1 jour.

Qui peut voir tes données

Il n’y a pas de mot de passe : un nom non protégé s’ouvre avec le nom seul, donc choisis un nom difficile à deviner. Un nom protégé demande en plus son code de récupération (Réglages → Code de récupération). L’éditeur peut consulter et supprimer les données pour l’assistance. Rien n’est vendu ni partagé.

Où et combien de temps

Hébergement : Supabase, serveurs en Irlande (Union européenne). Le site est servi par GitHub Pages. L’historique en ligne est effacé après 7 jours ; les réglages et le nom restent jusqu’à leur suppression. Pas de copie de sauvegarde. Apple et Google peuvent collecter leurs propres statistiques via leurs stores.

Tes droits

Tu peux consulter, corriger, exporter (fichier de sauvegarde) et supprimer tes données. Suppression : dans l’appli (Réglages → Supprimer l’utilisateur), sur la page time2relax.app/supprimer, ou par e-mail (sous 30 jours). Tu peux aussi porter plainte auprès de l’Autorité de protection des données. Base légale : fournir le service que tu demandes.
