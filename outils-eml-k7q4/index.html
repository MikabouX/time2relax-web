✅ Application installée ! Pour ouvrir tes mails directement avec elle :
  1. Fais un clic droit sur un fichier .msg → Ouvrir avec → Choisir une autre application.
  2. Choisis Lecteur EML / MSG, puis clique sur Toujours.
  3. Fais la même chose avec un fichier .eml.
  4. La première fois, si Edge demande d'autoriser l'ouverture du fichier, clique sur Autoriser.
